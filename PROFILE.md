## APIs

- **Secton API** — OpenAI-compatible inference REST API with chat-completions (streaming supported) and model-listing endpoints, using API-key authentication via the Authorization header. (`https://api.secton.org`)

> Confirmed live OpenAPI 3.0.0 contract at https://console.secton.org/openapi.json — byte-identical to `openapi/_original/secton-api-openapi.json`, declaring runtime host `https://api.secton.org`. The same document is also served at https://platform.secton.org/openapi.json. Two operations. Auth is an API key in the `Authorization` header (`ApiKeyAuth`); the server accepts both the bare key and a `Bearer` form. No MCP server, no A2A agent card, no published agent skills, no `/.well-known/` document on any host, no webhook or event surface. First-party TypeScript SDK `secton` on npm — **every published version carries an npm deprecation flag**, latest 1.0.2 dated 2025-07-04. No pricing page exists on any host.

### Lifecycle warning

On **2025-11-18** Secton announced it was "permanently shutting down Copilot, Secton Platform, and Secton API" (https://secton.org/blog/a-new-chapter), with the API operational only until **2025-12-19** and customer data deleted thereafter. As of 2026-08-16 the API host still answers with a live auth challenge, the OpenAPI is still served, the status page reports the `API` component operational over 90 days, and the Console Terms of Service governing API keys were re-issued **effective 2026-08-06**. Secton has published no retraction of the shutdown notice. Treat the lifecycle status as unresolved — see `lifecycle/secton-api-lifecycle.yml`.
